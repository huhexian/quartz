继续魔改我们的Begin主题，这次是修改WordPress自带的摘要样式，先贴出css代码：

```
/* 摘要 */
/* 修改 */
.abstract {
	color: #999;
	font-size: 14px;
}
/* 修改 */
.abstract fieldset {
	margin: 0 0 10px;
	padding: 5px 15px;
	border: 5px solid #ddd;
	border-radius: 10px;
}
/* 修改 */
.abstract legend {
	padding: 0 5px;
	color: #999;
	font-weight: bold;
	font-size: 18px;
}
```

将上面的代码粘贴至style.css文件，或后台-外观-主题-自定义，添加css代码。
