同样，按照惯例（好吧，不成文规定），每次放假回家必水一文。

快三个礼拜了，上次回学校是4.30，今天5.18了，而且今天下午在学校开了家长会，两点半结束，回到家就看看博客了。记得之前在网硕互联买主机的时候，送的一个com域名：huhexian.com

那时找不到身份证，今天回家找到了，就实名认证了，考虑博客以后的发展，用非主流men域名不太好，还是com主流，我就一不做二不休，等待实名通过，解析完成，就跑到主机数据库更换域名，在这里保存下用的代码，怕以后还会要用：

> `UPDATE wp_options SET option_value = replace(option_value,` `'www.mydomain.com'``,``'www.newdomain.com'``) ;`
> 
> `UPDATE wp_posts SET post_content = replace(post_content,` `'www.mydomain.com'``,``'www.newdomain.com'``) ;`
> 
> `UPDATE wp_comments SET comment_content = replace(comment_content,` `'www.mydomain.com'``,` `'www.newdomain.com'``) ;`
> 
> `UPDATE wp_comments SET comment_author_url = replace(comment_author_url,` `'www.mydomain.com'``,` `'www.newdomain.com'``) ;`

用起来是比较方便的，这样在博客后台也不用修改了，所有链接都改了。

还有一个，我一直在考虑用[yinji.org](http://yinji.org/)还是[huhexian.com](http://yinji.org/)，后来看了懿古今博客的一篇文章《[博客在于折腾：yigujin.cn改为www.yigujin.cn](https://www.yigujin.cn/1452.html)》，确实，博客在于折腾，那我就也直接用[yinji.org](http://yinji.org/)做主域名好了，[huhexian.com](http://yinji.org/)一样解析访问。

一切修改完之后，百度站长平台，百度统计平台全都更新了链接，自动提交收录也更新了，一切就这样。

最后，补充一句：

> 我更换域名了，新域名：[yinji.org](http://yinji.org/)，请添加了友链的博友修改下链接！谢谢！

以上就是本次水文内容。
